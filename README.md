# Свадебное портфолио — три варианта дизайна

Сайт-портфолио свадебного фотографа: три независимых варианта оформления
на выбор заказчику плюс демо direct-агента. Чистый HTML/CSS/JS, без сборки.

## Варианты

| Папка | Оформление |
|---|---|
| `site-1-ethereal` | воздушный светлый |
| `site-2-dark-luxe` | тёмный премиальный |
| `site-3-botanical` | ботанический, тёплый |
| `direct-agent` | демо direct-агента |
| `screenshots/` | скриншоты вариантов |

Открывать `index.html` в нужной папке — или смотреть варианты на GitHub Pages.
