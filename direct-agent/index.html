Возможности агента

🚀

Запуск кампании под ключ

Один вызов launch_campaign: группа → объявления → ключи → минус-слова. Все тексты проходят ФЗ-38-чек до заливки.

ФЗ-38AIDAguardrails
🔄

Модерационный цикл

Статус модерации, авто-правка отклонённых объявлений (REJECTED → fix → перепроверка Яндекса), лимит попыток.

DRAFT → ACTIVEREJECTED → fix
📊

Аналитика и ставки

Метрики по кампаниям и группам, ставки get/set, корректировки (гео / устройства / возраст / праздники −90..+1200%).

BidModifiersADGROUP отчёт
🧠

Семантика и лиды

Сбор семантического ядра: WordStat v4 + интент-классификация (горячие/тёплые/холодные), авто-минус-слова из поисковых запросов, лиды + CPL.

WordStat v4Leads APIЛукашов
🛡️

Система защиты бюджета

Hard limits, sanity-check, append-only аудит, kill-switch. Диапазон корректировок проверяется до API.

3000₽/группа15000₽/день500₽/ставка
🏗️

Песочница-симулятор

HTTP-эмулятор API Директа: виртуальное время, сюжеты (слив бюджета, обвал CTR, модерация), fault-injection. Репетиция до боя.

88 external сценариевfault-injection
